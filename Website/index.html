POR QUE O ACESSIFOOD EXISTE

Comer e vender online deve ser possível para todo mundo.

O AcessiFood é uma proposta de plataforma de alimentação digital inclusiva que une a descoberta e compra de refeições a ferramentas de acessibilidade e recursos práticos para pequenos comerciantes.

01OBJETIVO PRINCIPAL

Reduzir barreiras digitais.

Contribuir para que pessoas com diferentes necessidades consigam navegar, encontrar informações e realizar escolhas com mais independência, enquanto pequenos vendedores possam apresentar e organizar seus negócios sem uma interface excessivamente complicada.

02NOSSA PROPOSTA

Uma experiência adaptável para os dois lados.

Oferecer ajustes visuais e de interação para clientes, preferências alimentares e um fluxo de compra guiado; e, para vendedores, cadastro de loja, gestão de produtos e estoque, acompanhamento das vendas e relatórios.

O PROBLEMA QUE QUEREMOS ENFRENTAR

Acessibilidade também faz parte do atendimento.

Menus confusos, textos difíceis de ler, controles pequenos e informações alimentares pouco visíveis podem dificultar tarefas digitais cotidianas.

◎

Para clientes

Buscar pratos, aplicar filtros, comparar informações, montar a sacola e acompanhar pedidos com passos claros.

♿

Para diferentes necessidades

Ajustar tipografia, contraste, espaçamento, foco, animações e outros elementos para uma leitura mais confortável.

⌂

Para pequenos vendedores

Organizar catálogo, preços, estoque e status de pedidos, além de consultar vendas por cliente, data ou pedido.

FERRAMENTAS COM PROPÓSITO

O que cada recurso faz?

Os controles não são apenas visuais: cada um foi pensado para facilitar uma tarefa específica.

A1

Texto ampliado e fonte legível

Facilitam a leitura ao ampliar o texto ou usar uma família tipográfica simples e espaçamento mais confortável.

A2

Alto contraste e redução de cores

Ajudam a distinguir conteúdo e controles, ou reduzem a intensidade das imagens para quem prefere menos saturação.

A3

Espaçamento de linhas e letras

Cria mais separação visual entre linhas, palavras e caracteres para acompanhar o texto com mais facilidade.

A4

Realce de links e foco

Deixa links sublinhados e destaca com mais intensidade o elemento ativo durante a navegação pelo teclado.

A5

Guia de leitura

Exibe uma faixa horizontal que acompanha o ponteiro ou o elemento em foco para ajudar a seguir uma linha de texto.

A6

Modo foco e controles maiores

Reduz alguns elementos decorativos e amplia áreas clicáveis para tornar a interface menos distrativa e mais fácil de operar.

A7

Leitura de resumo por voz

Usa a síntese de voz disponível no navegador para anunciar um resumo da seção atual. A disponibilidade depende do dispositivo e do navegador.

A8

Teclado e pular para o conteúdo

Permite percorrer controles com Tab e Shift+Tab, acionar botões com Enter ou Espaço e ir direto ao conteúdo principal pelo link no topo.

A9

Modo escuro

Oferece uma paleta escura alternativa para quem prefere menos luminosidade na interface. O efeito pode variar conforme a tela e a iluminação do ambiente.

A10

Alinhamento à esquerda

Evita alinhamentos variados em blocos de texto e ajuda a localizar o começo de cada linha durante a leitura.

A11

Cursor ampliado

Ajuda a localizar o ponteiro e a perceber com mais facilidade onde será feita a próxima interação com o mouse.

A12

Escala de cinza

Apresenta a interface sem cores, como alternativa para pessoas que preferem reduzir estímulos cromáticos. Informações importantes continuam identificadas por texto e forma.

A13

Leitura por voz com controle

O resumo da seção pode ser lido em voz alta e a leitura pode ser interrompida a qualquer momento, conforme o suporte do navegador.

Experimente as ferramentas na prática.

As opções escolhidas ficam salvas no dispositivo e, quando conectado, no banco Supabase compartilhado.

INSTALAÇÃO PELO NAVEGADOR

Instalar como aplicativo

Em um site publicado em HTTPS, navegadores compatíveis podem instalar o AcessiFood na área de trabalho e abrir em uma janela própria.

A instalação aparecerá quando o site estiver hospedado em HTTPS e o navegador oferecer suporte. Por enquanto, use o download portátil.
Importante sobre esta versão

O ZIP contém a versão web portátil, não um instalador nativo .EXE ou .DMG. Para instalar pelo navegador, publique os arquivos em um endereço HTTPS. Pagamentos e entregas continuam demonstrativos. A sincronização entre site e Desktop exige configurar ambos com a mesma URL e chave pública do projeto Supabase.

Quer apenas abrir o protótipo no navegador? Baixar também a versão web portátil (.ZIP).

Banco de dados compartilhado

Site e Desktop usam o mesmo projeto Supabase.

Supabase
1
Crie as tabelas

No painel Supabase, abra o SQL Editor e execute o arquivo desktop/schema.sql do projeto.

2
Configure o site

Abra supabase-config.js e preencha a URL do projeto e a chave pública publishable/anon.

window.ACCESSIFOOD_SUPABASE_URL = 'https://seu-projeto.supabase.co';
window.ACCESSIFOOD_SUPABASE_ANON_KEY = 'sua-chave-publica';
3
Configure o Desktop

Na pasta desktop, copie .env.example para .env e use a mesma URL e chave pública.

cd desktop
npm install
npm start
4
Abra o site

Sirva a pasta principal por HTTP local ou hospede-a em HTTPS.

python -m http.server 5500

Atenção: o SQL incluído está configurado para demonstração sem login e permite acesso compartilhado amplo. Use apenas dados fictícios. Antes de publicar com dados reais, implemente Supabase Auth e políticas RLS restritas por usuário. Nunca use uma chave secret/service_role no site ou no Desktop.

Backup dos seus dados

Exporte uma cópia dos produtos, preferências, perfil e pedidos do AcessiFood, incluindo os dados carregados do banco compartilhado.

O backup pode conter informações de perfil e pedidos. Guarde o arquivo em local seguro. Quando a conexão está ativa, o Supabase é a fonte compartilhada entre o site e o Desktop.
